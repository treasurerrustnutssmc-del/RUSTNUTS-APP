uploaded to Play Console > Grow users > Store presence > Main store listing.

| File | Where it goes |
|---|---|
| `google-play/app-icon-512.png` | App icon (512 × 512) |
| `google-play/feature-graphic-1024x500.png` | Feature graphic (1024 × 500) |
| `google-play/phone-screenshots/01–08` | Phone screenshots (1080 × 1920), in this order |
